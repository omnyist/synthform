# Sounds

Alert and limit-break cues played by the overlay pages. One file has a copy of
its length living elsewhere:

- `limit-break-executed.ogg` (3.82 s as of 2026-09-12) plays on
  `limitbreak:executed`. bonk (`omnypro/bonk`) throws its volley on the same
  event after a delay in its `triggers.cfg` tuned to this file by ear. Nothing
  links the two. Swap or re-cut this file and update bonk's delay, or the
  volley lands off the beat.
